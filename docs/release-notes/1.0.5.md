- **Switch your sound output and microphone from the panel.** The new speaker and mic buttons on the Mute and Mute Microphone rows list the same devices as the Sound menu in Control Center. Pick one and the row follows it.
- **Bluetooth permission is asked for only when you want it.** New users are no longer asked at first launch: click **Allow…** on the Bluetooth row, or press its shortcut. If you've already allowed it, nothing changes.
- **Updates are better protected.** The update feed is now signed as well as the download, and a download's signature is checked before it's unpacked, so a tampered update is refused before it's opened.
- Switchboard now hands its AppleScript to macOS privately, instead of on a command line that other apps can read (it can include your Finder windows' folders). Its one outside library, Sparkle, now loads only from inside the app.
- The README has a new [Privacy and security](https://github.com/jhokanson00/Switchboard#privacy-and-security) section: what Switchboard asks permission for, what protects it, and how to report a security problem privately.
