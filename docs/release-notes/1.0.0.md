The first release of Switchboard: a menu bar panel of quick toggles, each showing your Mac's real current state.

- **Settings:** Dark Mode, Night Shift, Hide Desktop Icons, Hide Desktop Widgets, Autohide Dock, Autohide Menu Bar, Show Recent Apps in Dock, Show Hidden Files, Show Library Folder, Mute, Mute Microphone, Keep Awake (for a set time, or while an app is open) and Bluetooth.
- **Actions:** Start Screen Saver, Empty Trash (asks first), and Eject for disk images, network drives, USB sticks and SD cards. Hard disks stay connected.
- **Pomodoro timer** with 5 to 60-minute focus sessions, the minutes left in the menu bar, and notifications.
- **CPU and GPU meters** at the top of the panel.
- **Global keyboard shortcuts** for anything, with a suggested ⌃⌥⌘ set and an on-screen confirmation.
- **Restore original settings** puts back everything Switchboard changed. Launch at Login is optional.
