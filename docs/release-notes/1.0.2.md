- **Hide Desktop Icons** now works instantly, like System Settings' "Show Items: On Desktop", without restarting Finder. Finder still restarts while Stage Manager is on, and once to show icons hidden by an earlier version of Switchboard.
- **Show Hidden Files** could change the setting without restarting Finder, so nothing seemed to happen. Finder now restarts every time.
- After Finder restarts, Switchboard no longer opens extra copies of your Finder windows on Macs that reopen windows by themselves.
- A Finder that's slow to answer after a restart can no longer leave other toggles stuck.
